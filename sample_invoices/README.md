# Sample Invoices

This directory contains anonymized sample invoices for testing the invoice parser.

## Sample Files

Each sample file demonstrates different parsing challenges:

- `perfect_invoice.txt` - Clean, well-formatted invoice
- `handwritten_additions.txt` - Invoice with handwritten notes
- `negative_amounts.txt` - Invoice with credits/refunds
- `multi_page.txt` - Multi-page invoice format
- `ambiguous_descriptions.txt` - Invoice with typos and abbreviations
- `foreign_currency.txt` - Invoice with Euro amounts
- `formula_charges.txt` - Invoice with calculated charges
- `tax_separate.txt` - Invoice with separate tax line
- `subtotals.txt` - Invoice with multiple subtotals

## Usage

These samples can be used for:
- Manual testing
- Integration testing
- Performance benchmarking
- Documentation examples

## Privacy

All sample invoices are anonymized and contain no real PII or financial data.
